# Persona Trackers

Interactive social link calendars for **Persona 5 Royal**, **Persona 4 Golden** and **Persona 3 Reload**.

- Weekly availability grid, rank pips, social stat requirements and perks
- Month selector with lock / unlock / deadline dates
- Spoiler filter: hides anything that happens after the selected month
- Hide completed / maxed links
- Persona 5 Royal: all 33 Mementos requests with unlock dates
- Progress is stored in your browser (`localStorage`) — no server, no account

Each page is a single self-contained HTML file. The only external request is Google Fonts.

## Run

Open `index.html` in a browser, or publish with GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root).

## Notes

Data comes from community guides and some of them disagree on a few days and unlock dates.
Each page lists the conflicts under "Uncertain data" in its Notes section. Fan-made and unofficial;
